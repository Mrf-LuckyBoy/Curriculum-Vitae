# Curriculum-Vitae
This repository contains a personal CV/resume site built with HTML and CSS.

## Structure

- `index.html` contains the résumé content and semantic page structure.
- `styles/base.css` defines shared variables, typography, and page layout.
- `styles/resume.css` contains résumé-specific section and component styles.
- `styles/print.css` contains print-only pagination and presentation rules.

## Preview

Open `index.html` directly in a browser, or serve the directory locally:

```bash
python3 -m http.server 8000
```

Visit `http://localhost:8000`, then use print preview to check the final
résumé pagination.
